## Which one to start with

<Accordions type="single">
  <Accordion title="The PDF is a file on disk">
    Pass the path to `convert()`. See [Node.js and Bun](/docs/examples-node).
  </Accordion>
  <Accordion title="The PDF arrives over HTTP or from object storage">
    Pass the bytes as a `Buffer` or `ArrayBuffer`. pdf-raster never writes a
    temporary file. See [Node.js and Bun](/docs/examples-node#convert-bytes-from-memory).
  </Accordion>
  <Accordion title="Users upload PDFs in a web app">
    Start with the [route handler](/docs/examples-nextjs). Add the
    [upload and preview page](/docs/examples-nextjs-full-flow) if you also need
    the client side.
  </Accordion>
  <Accordion title="The response is too large">
    Lower the DPI, request fewer pages, or switch formats. WebP is lossless and
    about a third the size of PNG on text pages. JPEG is lossy and the smallest
    on pages with photos. For more than a few pages, store the images and
    return URLs instead of embedding base64 in JSON.
  </Accordion>
  <Accordion title="The images go to OCR or a model">
    Render at 300 DPI and pass `page.data` with `page.mimeType`. See
    [OCR and vision models](/docs/examples-ocr-vlm).
  </Accordion>
</Accordions>
